# Example User Response: Home To Nordkapp

This example shows a `sketch` for an ambiguous point-to-point route. It intentionally stops before detailed stop selection or the internal handoff artifact.

Assumptions: northbound only, 12-15 days, summer travel, a standard road vehicle, and a mixed scenic/practical pace.

Recommended route: use the hybrid Sweden and Finland northbound corridor with a northern Norway finish. It keeps the long southern transit efficient, then spends more time where the route becomes Arctic.

Main alternatives:

- Sweden and Finland efficiency route: simpler and ferry-light, but less scenic near the finish.
- Norway-heavy coastal route: more scenic, but slower and more dependent on ferries and weather.
