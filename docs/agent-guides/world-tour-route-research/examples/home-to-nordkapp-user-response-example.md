# Example User Response: Home To Nordkapp

This example shows the default user-facing output shape. It intentionally stops before the internal handoff artifact.

Recommended route: use the hybrid Sweden northbound / northern Norway finish. It keeps the long southern transit efficient, then spends the scenic budget where the route starts to feel Arctic.

Main alternatives:

- Sweden/Finland efficiency route: simpler and ferry-light, but less scenic.
- Norway-heavy coastal route: more memorable, but slower and more ferry-dependent.
